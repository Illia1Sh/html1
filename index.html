Що ж таке природа?

Природа — це все, що нас оточує: ліси, річки, гори, тварини та рослини.
Вона є джерелом життя для людини. Природа поділяється на живу і неживу.
До живої природи належать тварини, рослини, гриби та мікроорганізми.
Нежива природа включає повітря, воду, ґрунт, сонце та каміння.
Всі елементи природи взаємопов’язані між собою.
Якщо змінюється один компонент, це впливає на всю систему.
Природа забезпечує людину їжею, водою, киснем і ресурсами.
Без неї неможливе існування життя на Землі.
Тому дуже важливо берегти природу і не забруднювати навколишнє середовище.

Висновок

Природа — це дивовижний світ, який оточує нас щодня: ліси, річки, гори, моря, тварини та рослини.
Вона є джерелом життя для людини, адже забезпечує нас чистим повітрям, водою та природними ресурсами.
Саме завдяки природі існує життя на нашій планеті,
А люди, тварини й рослини можуть розвиватися та існувати в гармонії.
Природа не лише допомагає нам виживати, але й робить світ красивим, різноманітним та неповторним.
Тому дуже важливо берегти навколишнє середовище,
Дбати про чистоту та відповідально ставитися до нашої планети.
Кожна людина може зробити свій внесок: не смітити, економити ресурси,
піклуватися про тварин та допомагати природі.
Лише разом ми зможемо зберегти її красу для майбутніх поколінь 🌿

Форма

  1. Форми використовуються для введення, збору та відправки даних користувача.
  2. Основні атрибути тега <form> — action і method.
  3. Тег <input> призначений для створення полів введення даних.
  4. Основним атрибутом <input> є type, також часто використовується name.
  5. <input type="text"> показує звичайний текст, а <input type="password"> приховує символи.
  6. <input type="checkbox"> має вигляд квадрата з галочкою.
  7. <input type="radio"> має вигляд круглого перемикача.
  8. <textarea> — це багаторядкове текстове поле.
  9. Спадне меню створюється через теги <select> та <option>.
  10. Атрибут multiple дозволяє увімкнути множинний вибір у спадному меню.
  11. Форми в HTML використовуються для збору, введення та відправки даних користувача на сервер або для обробки за допомогою JavaScript.
  12. Основними атрибутами тега <form> є action (адреса, куди надсилаються дані) та method (спосіб відправки даних, наприклад GET або POST).
  13. Тег <input> використовується для створення різних полів введення даних у формах (текст, пароль, чекбокси, радіокнопки тощо).
  14. Основним обов’язковим атрибутом <input> є type, який визначає тип поля, також часто використовується name для передачі даних.
  15. <input type="text"> створює звичайне текстове поле для введення, а <input type="password"> приховує введені символи.
  16. <input type="checkbox"> відображається як квадрат, який можна відмітити або зняти відмітку.
  17. <input type="radio"> відображається як круглий перемикач, який дозволяє обрати один варіант із групи.
  18. <textarea> використовується для введення великого багаторядкового тексту, на відміну від <input type="text">, який однорядковий.
  19. Спадне меню створюється за допомогою тегів <select> та <option>, де користувач може обрати один або кілька варіантів.
  20. Атрибут multiple дозволяє активувати множинний вибір у випадаючому списку <select>.
  1. Таблицю зв’язаних стилів у документі підключають за допомогою тега <link> у секції <head>.
  2. Внутрішній стиль тега — це стиль, який задається через атрибут style всередині елемента.
  3. Селектор — це правило CSS для вибору елементів. Існують тегові, класові, id, групові та псевдоселектори.
  4. Клас в CSS — це спосіб об’єднання елементів. Синтаксис: .name {}. В HTML задається через class="name".
  5. Елемент може мати декілька класів, і декілька елементів можуть мати однаковий клас.
  6. Ідентифікатор (id) — це унікальна назва елемента в HTML.
  7. Елемент не може мати декілька id, і один id не повинен повторюватися на сторінці.
  8. Клас можна використовувати багато разів, а id повинен бути унікальним і має більший пріоритет.
  9. Групування селекторів дозволяє застосувати один стиль до кількох елементів одночасно.
  10. Псевдоселектор — це селектор стану або частини елемента.
  11. Для посилань використовують :link, :visited, :hover, :active.
  12. :hover змінює стиль елемента при наведенні курсора.
  13. Колір фону документа змінюють через background-color.
  14. Межу додають через border, наприклад: border: 2px solid black.
